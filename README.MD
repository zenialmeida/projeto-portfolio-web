# Projeto de Portfólio Pessoal

Projeto académico desenvolvido no âmbito da formação em Full Stack Web Development.

## Descrição

Este projeto foi criado como exercício prático de desenvolvimento web, com o objetivo de aplicar conhecimentos de HTML, CSS, estruturação de páginas, navegação, componentes visuais e boas práticas de otimização.

O website simula um portfólio pessoal e foi desenvolvido especificamente para fins formativos.

## Conteúdo do projeto

O projeto inclui várias páginas, entre elas:

- Página inicial
- Sobre
- Projetos
- Contactos

## Tecnologias utilizadas

- HTML5
- CSS3
- Font Awesome

## Conceitos abordados

- Estruturação de páginas web
- Navegação entre páginas
- Organização de conteúdo
- Estilização com CSS
- Utilização de ícones
- Estrutura responsiva
- Otimização e SEO

## Objetivo

O principal objetivo deste projeto foi consolidar conhecimentos de desenvolvimento web através da criação de um website de portfólio em contexto académico.
